# 🎀 Banana Player - 粉红少女版视频播放器

![Version](https://img.shields.io/badge/version-1.0.0-ff69b4)

一个充满少女心的自定义格式视频播放器，支持.ban格式的编码和播放。

## ✨ 主要特性

- 🎨 **粉红少女风格UI** - 渐变粉色背景，圆角设计，爱心装饰
- 📹 **自定义视频格式** - 支持.ban格式的编码和解码
- 🎬 **格式转换** - 将MP4/AVI/MOV等格式转换为.ban
- ▶️ **流畅播放** - 多线程播放，实时进度显示
- 🎯 **完整菜单栏** - 传统下拉菜单 + 现代按钮双重界面
- ⌨️ **快捷键支持** - 全面的键盘快捷键
- 👑 **会员系统** - 30天试用 + 黄金会员激活

## 📝 .ban格式说明

### 文件结构
```
[4字节] 魔数: "BAN1"
[4字节] FPS (帧率)
[4字节] Width (宽度)
[4字节] Height (高度)
[4字节] Frame Count (帧数)

循环每帧:
  [4字节] 帧大小
  [N字节] JPEG压缩的帧数据
```

### 特性
- JPEG质量: 85 (可在config.py中配置)
- 自动修正帧数统计
- 文件完整性校验
- 损坏帧自动跳过

## 🐛 常见问题

### Q: 转换后的.ban文件比原视频大？
A: .ban使用JPEG逐帧压缩，可能比高度压缩的MP4稍大，但保证了播放稳定性。

### Q: 如何激活黄金会员？
A: 点击"工具 → 激活黄金会员"，输入界面显示的提示密钥即可。

### Q: 播放大视频很慢？
A: 播放器会将所有帧加载到内存，建议处理较小的视频文件或分段处理。
