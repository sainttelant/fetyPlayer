🐛 问题描述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

症状：拖动进度条时程序崩溃

错误信息：
  RecursionError: maximum recursion depth exceeded
  while calling a Python object

发生位置：
  src/player.py:319  - display_frame() 中的 progress.set()
  src/player.py:381  - seek_video() 调用 display_frame()

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 原因分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这是一个典型的GUI回调循环问题：

  用户拖动进度条
       ↓
  触发 seek_video(value)
       ↓
  调用 display_frame(frame_idx)
       ↓
  更新进度条 progress.set(frame_idx)
       ↓
  再次触发 seek_video(value)  ← 形成死循环！
       ↓
  无限递归，程序崩溃 💥

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 修复方案
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

使用标志位（flag）防止递归：

1️⃣ 添加标志变量
   ┌─────────────────────────────────────────┐
   │ self.seeking = False  # 防止递归        │
   └─────────────────────────────────────────┘

2️⃣ 修改 display_frame()
   ┌─────────────────────────────────────────┐
   │ if not self.seeking:                    │
   │     self.seeking = True                 │
   │     self.progress.set(frame_idx)        │
   │     self.seeking = False                │
   └─────────────────────────────────────────┘

3️⃣ 修改 seek_video()
   ┌─────────────────────────────────────────┐
   │ if self.frames and not self.seeking:    │
   │     self.seeking = True                 │
   │     self.current_frame_idx = int(value) │
   │     self.display_frame(...)             │
   │     self.seeking = False                │
   └─────────────────────────────────────────┘
